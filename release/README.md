# 📚 Читательский дневник

Десктопное приложение для ведения читательского дневника на Windows.

---

## Возможности

- **Каталог книг** — добавление книг с названием, автором, жанром, форматом, обложкой и статусом чтения (В планах / Читаю / Прочитано / Брошено)
- **Трекер чтения** — ежедневные записи прочитанных страниц с указанием диапазона страниц и заметок
- **Прогресс-бар** — визуально показывает % прочитанного на карточке книги
- **Цитаты** — сохранение цитат к каждой книге с указанием страницы
- **Отзывы** — оценки по четырём критериям (идея, сюжет, персонажи, мастерство автора), текстовый отзыв, экспорт отзыва в .txt
- **Теги** — произвольные теги для книг с фильтрацией по тегу
- **Планы чтения** — план на месяц и на год
- **Аналитика** — статистика по страницам, выполнение целей, темп чтения
- **Графики** — визуализация чтения по месяцам и жанрам
- **Поиск** — поиск по названию, автору, жанру, цитатам, тегам и заметкам
- **Резервное копирование** — экспорт и импорт всех данных в JSON
- **Экспорт в Excel** — выгрузка данных в .xlsx
- **Тёмная и светлая тема** интерфейса
- **Системные уведомления** — напоминание о ежедневном чтении через Windows

---

## Системные требования

- Windows 10 / 11 (64-bit)
- MySQL Server 8.0 или новее
- Visual C++ Redistributable 2022

## Установка — пошаговая инструкция

### Шаг 1 — Установка Visual C++ Redistributable

Это системная библиотека, необходимая для работы приложения. Если она уже установлена — пропустите этот шаг.

1. Скачайте установщик по ссылке:
   **https://aka.ms/vs/17/release/vc_redist.x64.exe**
2. Запустите скачанный файл `vc_redist.x64.exe`
3. Нажмите «Установить» и дождитесь завершения
4. Перезагрузка не требуется

---

### Шаг 2 — Установка MySQL Server

MySQL — это база данных, в которой хранятся все ваши книги и записи.

1. Перейдите на сайт: **https://dev.mysql.com/downloads/mysql/**
2. В разделе «Select Operating System» выберите **Microsoft Windows**
3. Выберите строку **Windows (x86, 64-bit), MSI Installer** (файл ~50 МБ) и нажмите **Download**
4. На следующей странице нажмите **No thanks, just start my download**
5. Запустите скачанный `.msi` файл
6. В мастере установки выберите тип **Server only** — этого достаточно
7. На экране «Accounts and Roles» задайте пароль для пользователя **root**
   > ⚠️ Запомните или запишите этот пароль — он понадобится на Шаге 4
8. На экране «Windows Service» оставьте галочку **Start the MySQL Server at System Startup** — это позволит MySQL запускаться автоматически вместе с Windows
9. Нажимайте «Next» до завершения установки

**Проверка установки:**
- Нажмите `Win + R`, введите `services.msc`, нажмите Enter
- В списке найдите **MySQL80** (или MySQL)
- Статус должен быть **Выполняется**

---

### Шаг 3 — Создание базы данных

После установки MySQL нужно создать базу данных для приложения.

#### Способ А — через командную строку (рекомендуется)

1. Нажмите `Win + R`, введите `cmd`, нажмите Enter
2. Перейдите в папку с приложением командой (замените путь на ваш):
   ```
   cd "C:\Users\ВашеИмя\Desktop\ChitatelDnevnik"
   ```
3. Выполните команду (введите пароль root когда попросит):
   ```
   mysql -u root -p < init_db.sql
   ```
4. Если команда выполнилась без ошибок — база данных создана

#### Способ Б — через MySQL Command Line Client

1. Откройте **Пуск** → найдите **MySQL 8.0 Command Line Client**
2. Введите пароль root
3. Скопируйте и выполните следующую команду:
   ```sql
   CREATE DATABASE IF NOT EXISTS chitatel_dnevnik CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```
4. Должно появиться сообщение `Query OK`
5. Введите `exit` для выхода

#### Способ В — через MySQL Workbench (если установлен)

1. Откройте MySQL Workbench
2. Подключитесь к локальному серверу (localhost, пользователь root)
3. В верхнем меню выберите **File → Open SQL Script**
4. Откройте файл `init_db.sql` из папки с приложением
5. Нажмите кнопку **Execute** (молния ⚡) или `Ctrl+Shift+Enter`

---

### Шаг 4 — Настройка подключения

Приложению нужно знать пароль от MySQL. Для этого используется файл `.env`.

1. Откройте папку с приложением в Проводнике
2. Найдите файл `.env` — он уже есть в папке
   > Если файл не виден — включите отображение скрытых файлов:
   > Проводник → Вид → Показать → Скрытые элементы
3. Откройте `.env` любым текстовым редактором (Блокнот, Notepad++)
   > Правой кнопкой мыши на файле → Открыть с помощью → Блокнот
4. Файл выглядит так:
   ```
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=ваш_пароль_mysql
   DB_NAME=chitatel_dnevnik
   ```
5. Замените `ваш_пароль_mysql` на пароль который вы задали при установке MySQL
6. Сохраните файл (`Ctrl+S`)

**Пример заполненного файла:**
```
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=MyPassword123
DB_NAME=chitatel_dnevnik
```

> ⚠️ Не добавляйте кавычки вокруг пароля. Пишите пароль как есть.

---

### Шаг 5 — Первый запуск

1. Дважды щёлкните на `ChitatelDnevnik.exe`
2. Если появится окно «Защитник Windows» — нажмите **Подробнее** → **Выполнить в любом случае**
3. При первом запуске приложение автоматически создаст все необходимые таблицы в базе данных
4. Откроется главное окно приложения — можно начинать добавлять книги!

## Структура файлов в папке

```
ChitatelDnevnik.exe   — основной исполняемый файл приложения

data\                 — создаётся автоматически: обложки книг и настройки
```

## Использование приложения

### Добавление книги
1. На главной странице нажмите **+ Новая книга**
2. Заполните поля: название, автор, жанр, количество страниц
3. Выберите статус: **В планах / Читаю / Прочитано / Брошено**
4. Нажмите **Сохранить**

### Трекер чтения
- Внизу главной страницы находится блок **Трекер**
- Укажите дату, выберите книгу, введите диапазон страниц (например: с 15 по 42)
- Нажмите **Сохранить запись**
- Прогресс-бар на карточке книги обновится автоматически

### Цитаты
- Откройте книгу → вкладка **Цитаты**
- Введите текст цитаты и нажмите **Добавить**
- Можно указать номер страницы

### Отзыв
- Откройте книгу → вкладка **Отзыв**
- Передвиньте слайдеры оценок (1–5) по каждому критерию
- Напишите текстовый отзыв
- Нажмите **Сохранить** — отзыв сохраняется вместе с книгой

### Резервное копирование
- **Экспорт**: Настройки → **Экспорт резервной копии** → выберите куда сохранить JSON файл
- **Импорт**: Настройки → **Импорт резервной копии** → выберите ранее сохранённый JSON файл

> Рекомендуется делать резервную копию раз в неделю и перед переустановкой приложения.

## Частые проблемы и решения

### Приложение не запускается (чёрный экран или сразу закрывается)

**Причина:** не установлен Visual C++ Redistributable.

**Решение:** скачайте и установите:
https://aka.ms/vs/17/release/vc_redist.x64.exe

---

### Ошибка «Не удалось подключиться к MySQL» или «10061»

**Причина:** служба MySQL не запущена.

**Решение:**
1. Нажмите `Win + R`, введите `services.msc`, нажмите Enter
2. Найдите в списке **MySQL80** (или MySQL, MySQL57)
3. Если статус не «Выполняется» — нажмите правой кнопкой → **Запустить**
4. Снова запустите приложение

Чтобы MySQL запускался автоматически:
- Правой кнопкой на MySQL80 → **Свойства**
- Тип запуска: **Автоматически**
- Нажмите **ОК**

---

### Ошибка «Файл .env не найден» или «DB_HOST: None»

**Причина:** файл `.env` отсутствует или находится не в той папке.

**Решение:**
1. Убедитесь что файл `.env` находится в той же папке что и `ChitatelDnevnik.exe`
2. Файл должен называться именно `.env` (с точкой в начале, без расширения)
3. Если файл не виден — включите отображение скрытых файлов в Проводнике:
   Вид → Показать → Скрытые элементы

---

### Ошибка «Access denied» или «Неверный пароль»

**Причина:** неверный пароль в файле `.env`.

**Решение:**
1. Откройте файл `.env` в Блокноте
2. Проверьте значение `DB_PASSWORD` — оно должно совпадать с паролем root в MySQL
3. Убедитесь что нет лишних пробелов или кавычек вокруг пароля
4. Сохраните файл и перезапустите приложение

Если вы забыли пароль root — его можно сбросить через MySQL Installer (раздел Reconfigure).

---

### База данных не создана — ошибка «Unknown database»

**Причина:** скрипт `init_db.sql` не был выполнен.

**Решение:** выполните Шаг 3 из инструкции выше (создание базы данных).

---

### Обложки книг не отображаются после переноса папки

**Причина:** пути к обложкам хранятся абсолютными.

**Решение:** переназначьте обложки вручную через кнопку **Выбрать обложку** на карточке книги.

---

## Резервное копирование перед удалением

Перед удалением или переустановкой приложения обязательно сделайте резервную копию:

1. Откройте приложение
2. Перейдите в **Настройки**
3. Нажмите **Экспорт резервной копии**
4. Сохраните файл `.json` в надёжное место (например, на рабочий стол или в облако)

После переустановки:
1. Запустите приложение
2. Перейдите в **Настройки**
3. Нажмите **Импорт резервной копии**
4. Выберите сохранённый `.json` файл
