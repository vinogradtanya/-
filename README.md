# 📚 Читательский дневник

Десктопное приложение для ведения читательского дневника на Windows.

---

## Возможности

- **Каталог книг** — добавление книг с названием, автором, жанром, форматом, обложкой и статусом чтения (В планах / Читаю / Прочитано / Брошено)
- **Трекер чтения** — ежедневные записи прочитанных страниц с указанием диапазона страниц и заметок
- **Прогресс-бар** — визуально показывает % прочитанного на карточке книги
- **Цитаты** — сохранение цитат к каждой книге с указанием страницы
- **Отзывы** — оценки по четырём критериям (идея, сюжет, персонажи, мастерство автора), текстовый отзыв, экспорт отзыва в .txt
- **Теги** — произвольные теги для книг с фильтрацией по тегу
- **Планы чтения** — план на месяц и на год
- **Аналитика** — статистика по страницам, выполнение целей, темп чтения
- **Графики** — визуализация чтения по месяцам и жанрам
- **Поиск** — поиск по названию, автору, жанру, цитатам, тегам и заметкам
- **Резервное копирование** — экспорт и импорт всех данных в JSON
- **Экспорт в Excel** — выгрузка данных в .xlsx
- **Тёмная и светлая тема** интерфейса
- **Системные уведомления** — напоминание о ежедневном чтении через Windows

## Системные требования

- Windows 10 / 11 (64-bit)
- MySQL Server 8.0 или новее
- Visual C++ Redistributable 2022 (если не установлен — скачать ниже)

## Установка для пользователей

Подробная инструкция находится в файле `release\README.md`.

Краткий порядок:

1. Установите **Visual C++ Redistributable 2022**:
   https://aka.ms/vs/17/release/vc_redist.x64.exe

2. Установите **MySQL Server 8.0+**:
   https://dev.mysql.com/downloads/mysql/
   - Тип установки: **Server only**
   - Задайте пароль для пользователя **root** — запомните его

3. Создайте базу данных (в папке с приложением):
   ```
   mysql -u root -p < init_db.sql
   ```

4. Откройте файл `.env` в папке с приложением и укажите пароль:
   ```
   DB_HOST=localhost
   DB_PORT=3306
   DB_USER=root
   DB_PASSWORD=ваш_пароль_mysql
   DB_NAME=chitatel_dnevnik
   ```

5. Запустите `ChitatelDnevnik.exe`

## Для разработчиков — запуск из исходников

### Требования

- Python 3.12
- MySQL Server 8.0+

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка

Создайте файл `.env` в корне проекта (скопируйте из `.env.example`):

```bash
copy .env.example .env
```

Откройте `.env` и укажите пароль MySQL.

### Запуск

```bash
py -3.12 app.py
```

### Сборка .exe

```bash
build.bat
```

Готовый `.exe` и все файлы для дистрибуции появятся в папке `release\`.

## Частые проблемы

**Приложение не запускается**
- Установите Visual C++ Redistributable: https://aka.ms/vs/17/release/vc_redist.x64.exe

**Ошибка подключения к MySQL (10061)**
- Убедитесь что служба MySQL запущена: `Win+R` → `services.msc` → MySQL80 → Запустить

**Файл .env не найден**
- Файл `.env` должен лежать в той же папке что и `ChitatelDnevnik.exe`
- Имя файла: именно `.env` (с точкой в начале, без расширения)

**Неверный пароль**
- Проверьте `DB_PASSWORD` в `.env` — без кавычек, без лишних пробелов

## Резервное копирование

- **Экспорт**: Настройки → Экспорт резервной копии → сохранить JSON файл
- **Импорт**: Настройки → Импорт резервной копии → выбрать JSON файл

Рекомендуется делать резервную копию перед переустановкой приложения.
